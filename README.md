# Soil-Shear-Strength-Prediction

This repository contains the data and Python code associated with the study:

> **Physical-state variables and a unified particle-size distribution descriptor for predicting soil shear strength**

## Purpose

This study explores how particle-size distribution and physical state can be considered together when predicting soil cohesion and internal friction angle. Its central component is a unified particle-size distribution descriptor designed to represent soil grading within a consistent framework.

## Research contribution

Conventional grain-size indices describe selected points or features of a particle-size distribution curve. The proposed descriptor provides an alternative way to summarize the distribution for strength prediction. The study examines its predictive contribution alongside physical-state variables and compares the resulting models with those using conventional grain-size indices.

## Repository contents

The data and Python code are provided to:

- calculate the unified particle-size distribution descriptor;
- prepare soil-property data;
- train and evaluate the prediction models;
- reproduce the main results and figures in the study.

## Disclaimer

This code was developed for research purposes. Model predictions should not replace laboratory or in-situ testing in engineering practice.
